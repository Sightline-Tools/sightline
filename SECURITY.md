# Sightline security policy

## Supported versions

Security fixes are provided for the latest public-beta release. Sightline officially supports Windows 11 x64.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, private data, screenshots, or encounter logs. Include the affected Sightline version and build commit, reproduction steps, and the security impact. You may generate a sanitized support bundle from Sightline for environment details.

The maintainers will acknowledge a complete report as availability permits and will coordinate disclosure after a fix is available. Never test against another person's computer or data without permission.
