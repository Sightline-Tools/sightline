Welcome to Sightline

Sightline is a local-first combat parser. It runs entirely on this computer: capture, OCR, encounter data, and settings stay local unless you explicitly export them.

Passive-capture boundary: Sightline only reads pixels inside the rectangle you select. Select only the combat text you want to parse and avoid areas that may show private messages or personal information.

For the most accurate setup, open your game first and arrange its combat text where you normally keep it. If you would rather look around first, you can return to this guide from Settings whenever you are ready.

1. Select the combat region

Keep the game and its combat text visible, then drag across only the text area you want Sightline to read. The selector supports display scaling and multiple monitors.

Optional foreground-application restriction is available later in Settings.

2. Test OCR

Sightline will capture one frame and recognize it in memory. The screenshot is not saved.

3. Start parsing

Your setup is ready. You can change the region and privacy controls later in Settings.
